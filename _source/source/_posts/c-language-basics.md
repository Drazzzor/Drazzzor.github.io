## 接触的第一门语言是 C

大一上学期开的是 C 语言。

C 语言是面向过程的，对初学者了解算法的细节比较友好，而且没有太多语法糖，要求编程者知道每一行到底在干什么。

## 第一个坎：指针

指针大概是劝退最多人的地方。卡了我整整一天。

真正让我想通的是一句话：**指针是一个变量，这个变量里存的是地址。** 就这么简单，之前我一直把它当成某种神秘的符号。

```c
int a = 10;
int *p = &a;   // p 存的是 a 的地址
printf("%d\n", *p);  // *p 就是取出那个地址上的值，输出 10
```

`&` 是取地址，`*` 是按地址取值。这两个符号在一开始总被我搞反。在纸上画内存格子、画箭头，有了可视化的图示，再看代码就有感觉了。

## 第三个坎：数组和字符串

C 里的字符串其实是字符数组，以 `\0` 结尾。这个设计让很多事情变得需要小心。

```c
char s[] = "abc";   // 实际占 4 个字节：a b c \0
```

还有一个常见的坑是数组越界。C 不会检查，写超了也照常运行，只是可能改到别的内存，然后在完全无关的地方报错。这种 bug 找起来最费时间，所以现在我写完循环一定要看一眼边界条件。

## 一点经验

- **要会读报错**。C 的报错信息比较详细，行号和原因都有。
- **要会打断点调试**。打断点配合单步调试能准确把握代码的运行逻辑。
- **画内存图**。指针和数组这类东西，纸上画一遍胜过盯着代码看十遍。
