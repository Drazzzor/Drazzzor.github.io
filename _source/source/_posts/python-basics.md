## 上手最快的一次

学完 C 和 Java 再碰 Python，第一个感觉是轻松。

同样输出一句话，Python 只要一行：

```python
print("Hello")
```

没有类，没有分号，没有类型声明，也不用先编译。写一个 `.py` 文件，命令行 `python hello.py` 就能跑。

这种轻快感对我这种刚开始学的人来说很重要，它让注意力能放在解决问题上，而不是放在语法规定上。

## 缩进是语法

Python 用缩进表示代码块，这让写惯了花括号的我很不习惯。

```python
if score >= 60:
    print("及格")
else:
    print("不及格")
```

缩进错了程序要么报错要么逻辑不对。我踩过的坑是把 Tab 和空格混用，肉眼看不出区别，运行时却报错。后来我在编辑器里设成"Tab 自动转 4 个空格"，这类问题就没再出现。

## 动态类型的两面

Python 的变量不需要声明类型：

```python
a = 10
a = "现在是字符串"
```

这很灵活，但也埋着问题。有一次我写了一个累加，中间混进了一个字符串，运行到一半才报错，而不是在写的时候就提示。C 和 Java 会在编译阶段拦住这类错误，Python 不会。

所以现在我在关键的地方会加一句检查：

```python
if not isinstance(value, (int, float)):
    raise TypeError("需要数字")
```

看起来啰嗦，但能省下后面找错的时间。

## 列表和字典真好用

Python 的内置数据结构是我最喜欢的地方。

```python
names = ["张三", "李四", "王五"]
info = {"name": "张三", "age": 20}

for n in names:
    print(n)
```

在 C 里写这些要自己管长度和内存，Java 里要写不少样板代码，Python 直接就能用。切片也很方便，`names[1:]` 就能取后半段。

## 几个踩过的细节

- **可变对象做默认参数会出问题**。`def f(x=[])` 里的列表是所有调用共享的，会一直累积。要用 `None` 再在函数里判断。
- **`=` 和 `==` 别写错**。Python 里 `=` 赋值、`==` 比较，写错的话不一定报错，可能只是逻辑悄悄变了。
- **尽量用虚拟环境**。`python -m venv venv` 建一个独立环境，避免不同项目的包互相干扰。我一开始都装在全局，后来装了新版本的库，旧项目就跑不起来了。

## 最后一点想法

三门语言学下来，我的感受是：C 让人知道底层在做什么，Java 让人养成规范的工程习惯，Python 让人把想法快速变成能跑的东西。

初学阶段纠结"该学哪门"其实意义不大，先挑一门写起来，比什么都强。真正难的地方不在语法，而在于把一个问题拆成可以一步步执行的步骤——这一点哪门语言都帮不上忙。
